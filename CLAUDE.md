# Claude Project Instructions

Before working on this repository:

1. Read `PROJECT_CONTEXT.md` as the primary cross-session project context.
2. Read and follow `AGENTS.md` for repository-wide operating and Git rules.
3. Verify the current working tree and Git state instead of assuming the context document is current.

Keep changes minimal and scoped, preserve Manifest V3/browser-runtime compatibility, protect cleanup and privacy invariants, run appropriate checks, and update `PROJECT_CONTEXT.md` when project state or decisions materially change.

Normal verified work may be committed and pushed for backup as described in `PROJECT_CONTEXT.md`; tags, GitHub Releases, and store publication require explicit user approval. A task-specific instruction to stop for review before commit or push takes precedence.
